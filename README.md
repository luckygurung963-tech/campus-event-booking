# campus-event-booking
## Problem
Students often miss campus events because listings are scattered across social media, emails and posters. Society organisers also struggle to manage RSVPs and ticket limits. Existing tools often collect more personal data than they need.

## Our solution
A web app where students can discover and book campus events, and organisers can create events and manage attendance. It is designed to collect minimal personal data and to be accessible and efficient.

## MVP features
- Browse and search events without an account
- Register and log in to book tickets (with input validation, such as ticket limits)
- Organiser dashboard to create and manage events
- Booking confirmation
